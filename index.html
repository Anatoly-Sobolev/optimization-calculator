Как пользоваться

Выберите задание, затем вариант из методички или «свои коэффициенты». Условие, преобразования, таблицы, графики и проверка строятся из фактических вычислений в точных дробях; конечные десятичные дроби показаны десятичными, остальные — обыкновенными.

Порядок чтения решения. Сразу под условием — карточка «Итог»: ответ, сверка с источником и ссылки на нужные разделы. Памятка по методу свёрнута («Показать алгоритм»). В пошаговом разборе каждый шаг — три карточки (входит, выходит, ведущий элемент): наведите на карточку — в таблице подсветятся её ячейки; кнопка «▶ Разобрать шаг» показывает их по очереди и открывает новую таблицу. Мини-график рядом показывает, как меняется цель от таблицы к таблице. Если задача помещается на плоскость (x₁; x₂), раздел «Геометрия» показывает, по каким вершинам идёт симплекс-метод; точки кликабельны.

Графики. Плоскость можно перетаскивать мышью или пальцем, масштаб — кнопками «−»/«+» или Ctrl + колесо; «Вписать» возвращает исходный вид, «±» показывает все четыре четверти. Справа — список ограничений (включая x ≥ 0): наведите на строку, чтобы увидеть полуплоскость; ◐ закрашивает её; флажок убирает ограничение из области — видно, как область меняется без него. Режим «Построить по шагам» добавляет ограничения по одному и объясняет, какую сторону прямой берём и почему (подстановка точки). Щелчок по графику ставит пробную точку и показывает, какие ограничения она нарушает; ползунок двигает линию уровня вручную.

Режим тренажёра (переключатель рядом с выбором варианта). Ответы размыты — щелчок открывает раздел. В симплекс-таблицах вы сами выбираете ведущий столбец и строку и считаете отмеченные ячейки новой таблицы; на ошибку калькулятор отвечает подсказкой, а не ответом, и считает ошибки. На графике нужно щёлкнуть по оптимальной вершине, а в режиме «по шагам» — по нужной стороне каждой прямой. В двойственной задаче сборника — расставить знаки ограничений и условий на yᵢ.

Ещё: «🎚 Что если…» под графиком меняет правые части и коэффициенты цели — видно, как сдвигается оптимум, и что изменение f* на единицу ресурса равно двойственной оценке yᵢ. Для задач с тремя переменными строится объёмный многогранник с путём симплекс-метода (вращается мышью). «🖨 Печать / PDF» собирает чистую версию решения со всеми таблицами. Клавиши ← → листают таблицы. Адрес страницы запоминает выбранный вариант — ссылкой можно поделиться.

Задание 1. Графический метод

Каждое ограничение — полуплоскость, граница — прямая через точки (0; b/a₂) и (b/a₁; 0); сторона определяется подстановкой (0; 0). Пересечение полуплоскостей — допустимая область. Линию уровня c₁x₁ + c₂x₂ = const сдвигают по градиенту (c₁; c₂) до последней общей точки с областью; её координаты — решение системы двух граничных прямых.

Задание 2. Симплекс-метод

Приведённая задача: все ограничения — равенства, в каждом есть базисная переменная с коэффициентом 1, цель выражена через небазисные, все b ≥ 0. Для «≤» добавляют остатки — они и есть стартовый базис. Базис — переменные, подписанные слева у строк: они равны своему b, остальные равны 0.

  1. Нет отрицательных в строке f — решение оптимально.
  2. Есть столбец с минусом в строке f и без положительных элементов — f не ограничена.
  3. Ведущий столбец — самое отрицательное число строки f (входит в базис).
  4. Ведущая строка — минимум b ÷ a при a > 0 (выходит из базиса).
  5. Ведущую строку делят на ведущий элемент, из остальных вычитают её, умноженную на их число в ведущем столбце.

Задание 3. Метод искусственного базиса

«≥» превращают в равенство, вычитая излишек. Готового базиса нет, поэтому в каждое уравнение добавляют искусственную tᵢ. Этап 1: минимум h = Σtᵢ (в таблице строка −h, так как алгоритм ищет максимум; её числа — минус суммы столбцов). h* > 0 — допустимая область пуста; h* = 0 — t выводят из базиса, их столбцы удаляют. Этап 2: строка −f выражается через небазисные переменные, далее обычный симплекс-метод.

Задание 4. Двойственная задача

Для задачи на max неравенства приводят к «≤». Каждому ограничению — yᵢ ≥ 0, цель g = Σbᵢyᵢ → min; каждому xⱼ ≥ 0 — ограничение Σaᵢⱼyᵢ ≥ cⱼ. Условия дополняющей нежёсткости: в каждой паре сопряжённых условий хотя бы одно — равенство (xⱼ > 0 ⇒ ограничение j двойственной — равенство; ограничение i прямой строгое ⇒ yᵢ = 0). Если уравнений не хватает (вырожденная вершина), оставшиеся ограничения учитывают как неравенства — оптимум двойственной может быть не единственным.

Задачи сборника для практических занятий

Переключатель «Источник задач» открывает разделы 2.2, 2.3, 2.4 и 2.6 сборника заданий (Зыкина и др.). В этих задачах бывают уравнения, разное число переменных и ограничений, свободный член цели и условия на знак переменных. 2.2: если переменных больше двух, их выражают из уравнений через x₁ и x₂ (метод Гаусса), условия xⱼ ≥ 0 становятся неравенствами на плоскости. 2.3 и 2.4: двухэтапный метод: в «≤» прибавляется остаток, из «≥» вычитается излишек, искусственные переменные добавляются туда, где нет готового базиса (в 2.3 — в каждое уравнение); итог этапа 1 — допустимое базисное решение. 2.6: двойственная задача строится по таблице соответствия знаков; xⱼ ≥ 0 и xⱼ ≤ 0 — условия на знак, другие границы — обычные ограничения, переменная без условия на знак — любого знака. Ответы сборника показаны как справочные: в некоторых из них есть опечатки, итог всегда определяется расчётом.

Особые случаи

Калькулятор не выдаёт ответ, если допустимая область пуста, цель не ограничена или алгоритм не может продолжить: в таком месте показывается, что именно произошло. Отдельно отмечаются вырожденные решения и несколько оптимумов. От зацикливания защищает правило Бленда.

Источники условий: методические указания к РГР (Девятерикова, Борисовский); сборник заданий для практических занятий по методам оптимизации (Зыкина и др.). Все вычисления выполняются в браузере, без сети.
