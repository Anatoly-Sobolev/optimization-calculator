# Учебная среда по методам оптимизации

Основная страница — `index.html`. Она подключает `learning.js` и `learning.css`
из той же папки. Сборка для работы сайта не нужна. Для GitHub Pages эти три
файла должны находиться рядом. PDF и отдельные HTML-файлы источников не изменены.

## Как пользоваться

Выберите источник, тему и вариант (либо решите задачу со своими коэффициентами),
затем нажмите **«Начать обучение»**.

- **Понять решение**: цель этапа и объяснение перед открытием преобразования.
- **Следующий логический этап**: вопрос по текущему состоянию задачи; после
  правильного ответа открываются объяснение, преобразование и следующий этап.
- **Разобрать ошибку или выбор**: оценка предложенного студентом ответа с
  математической обратной связью.
- **Решить самостоятельно**: ввод числовых результатов, в том числе точных дробей;
  для логических преобразований — выбор действия.
- **Викторина по теме**: до пяти вопросов, распределённых по этапам текущей задачи.
- **Подготовка к экзамену**: подборка из шести разных тем, чередующих два источника;
  после первых двух задач автоматические подсказки отключаются, оставаясь по запросу.

Уровни **Кратко / Подробно / Глубоко** изменяют отбор вопросов и пояснения.
Математическая трасса не пересчитывается другим методом. Изменение настроек
открывает отдельное сохраняемое прохождение; можно вернуться к прежним настройкам.

При ошибке переход закрыт. После ответа нужно нажать **«Следующий этап»**, чтобы
успеть прочитать пояснение. **«Показать объяснение / сдаться»** раскрывает ответ
и учитывается как помощь. Преобразование можно повторить или остановить.
В конце открывается полный исходный разбор со всеми его анимациями и графиками.
Классический тренажёр в прежних темах сохранён.

## Архитектура

В `index.html` добавлены начало захвата результатов, подключение учебной панели
после существующего рендера и два подключения файлов. Тела решателей не менялись.

Учебный модуль наблюдает за возвращаемыми результатами существующих решателей
во время построения текущего решения. Адаптеры используют их таблицы, фазы,
отсечения, перевозки, потенциалы, проходы по сети и двойственные сертификаты.
Общий контракт этапа: `id`, `title`, `before`, `prompt`, `answer`, `options`,
`reason`, `hint`, `deep`, `after`, `tier`, `skill`. Для числового ответа применяется
существующий `Q.parse` и точное сравнение рациональных чисел.

До ответа показывается исходное состояние этапа с релевантной подсветкой.
После ответа показывается его результат; изменившиеся клетки выделяются.
Отмена анимации защищена счётчиком поколения, поэтому старый шаг не может
дорисоваться после смены задачи. При `prefers-reduced-motion` результат появляется
сразу. Печать показывает полное решение, даже когда оно скрыто учебным сценарием.

## Прогресс

Ключ localStorage: `optimization.learning.v1`. Сохраняются настройки, текущий
этап и ответы до 80 маршрутов, число ошибок, использование подсказок и сдачи,
серии правильных ответов, завершения тем и самостоятельное освоение.
Освоение означает успешное самостоятельное прохождение выбранного маршрута,
а не доказательство знания всех вариантов темы. Режим чтения не присваивает
самостоятельное освоение. Для экзамена сохраняется текущая подборка.

Сброс: **«Освоение тем и локальный прогресс» → «Сбросить учебный прогресс»**.
Данные никуда не отправляются. Если браузер запрещает localStorage, панель
сообщает, что прогресс останется только до закрытия страницы.

## Проверка и границы проверки

Фактические результаты на **3 ноября 2026**, Windows / Chromium:

- Все **500** сочетаний отрисованы без ошибки; текст полного исходного решения
  совпал с контрольным рендером без учебного модуля.
- Структурно проверены **10 846** этапов всех уровней: эталонный ответ принимается,
  у вопроса с выбором есть альтернативы, нет пустых маршрутов.
- Завершены **120** кратких прохождений (20 маршрутов × 6 режимов) и **20**
  глубоких самостоятельных прохождений. Проверены эквивалентные дроби.
- В каждом из 20 маршрутов отработал ввод собственных коэффициентов.
- Полностью пройдены смешанные подборки из шести задач обоих источников.
- Проверены неверный ответ без перехода, подсказка, сдача, восстановление после
  перезагрузки, сброс localStorage, печать и отключённое движение.
- На ширине **390 px** проверены все 20 маршрутов; на **1366 px** проверена
  ширина учебной панели. Скриншоты просмотрены. Исправлены переполнение списка
  транспортных вариантов и попадание панели в узкую колонку навигации.
- Проверены Tab / Shift+Tab и видимый фокус; запущенное повторное преобразование
  отменяется при смене темы. Проверены переключатели обоих источников и варианта.

Первый полный прогон выявил мобильное переполнение; оно исправлено.
Следующий выполнил проверки всех вариантов и 140 прохождений, затем остановился
на некорректном предположении самого теста о `:focus-visible` после программного
фокуса. Тест исправлен на реальный ввод Tab; заключительные взаимодействия
повторно проверены командой `node tests/learning.cjs --finish-only`, код выхода 0.
Результаты основного охвата — `test-results/learning-report.json`, успешного
заключительного прогона — `test-results/learning-interaction-report.json`.

Автоматический браузерный сценарий: `npm ci`, затем `npm test`.
Нужен Chromium из Playwright либо путь к браузеру в переменной `CHROMIUM_PATH`.
Node/Playwright нужны только для проверки, не для открытия сайта.
Машинный отчёт находится в `test-results/learning-report.json`;
скриншоты — в `test-results/`. Эти артефакты и зависимости исключены из Git.

Проверка сравнивает текст всего прежнего решения с рендером, в котором
учебный модуль отключён, для всех вариантов. Дополнительно проходит шесть
режимов на представителях всех маршрутов, глубокий самостоятельный режим,
собственные коэффициенты, смешанный экзамен, блокировку ошибочного ответа,
дроби, сохранение после перезагрузки, сброс, печатные стили, reduced motion,
мобильную ширину и отмену анимаций при смене темы.

Не исчерпываются все возможные пользовательские коэффициенты, все комбинации
настроек на каждом из 500 вариантов, все браузеры и физические устройства.
